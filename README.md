# Bimo — Aplicación de bienestar emocional

## 1. Descripción del proyecto

Bimo es una aplicación web de acompañamiento emocional orientada al bienestar de las personas en el contexto laboral. Utiliza una mascota virtual que acompaña al usuario en el registro de su bienestar y entrega mensajes y sugerencias de autocuidado mediante respuestas predefinidas.

El proyecto busca facilitar el reconocimiento del estado emocional y favorecer la identificación de tendencias personales, resguardando la privacidad de los registros individuales.

## 2. Objetivo del MVP

Desarrollar una aplicación web que permita registrar el bienestar emocional, consultar la evolución personal e interactuar con una mascota virtual mediante reglas y respuestas predefinidas.

## 3. Funcionalidades contempladas

- Inicio de sesión y acceso según perfil.
- Activación de cuentas mediante invitación.
- Registro del bienestar emocional.
- Consulta de la evolución personal.
- Interacción con Bimo mediante respuestas predefinidas.
- Indicadores preventivos y panel organizacional con datos agregados, contemplados para etapas posteriores del MVP.

## 4. Tecnologías

- **Lenguaje:** Python.
- **Backend:** Flask.
- **Frontend:** HTML, CSS y JavaScript.
- **Base de datos local:** SQLite.
- **Gestión de datos:** Flask-SQLAlchemy.
- **Editor de código:** Visual Studio Code.
- **Control de versiones:** Git y GitHub.
- **Diseño de interfaces:** Figma.

El entorno de despliegue para producción se definirá durante la planificación técnica.

## 5. Estado del proyecto

El proyecto se encuentra en etapa de definición y desarrollo inicial. Se están preparando los requerimientos, los prototipos de interfaz, el modelo de datos y la planificación del producto mínimo viable (MVP).

## 6. Privacidad y alcance

Bimo tiene un enfoque preventivo y de bienestar emocional. No realiza diagnósticos clínicos. Los registros personales deben mantenerse privados y los indicadores organizacionales deben presentarse de forma agregada, aplicando medidas para reducir el riesgo de identificación de las personas.

## 7. Uso de inteligencia artificial

Se utilizaron herramientas de asistencia basadas en inteligencia artificial como apoyo en tareas de planificación, redacción y diseño del proyecto. La interacción prevista de Bimo en el MVP funciona mediante reglas y respuestas predefinidas, sin utilizar IA generativa para generar sus respuestas.

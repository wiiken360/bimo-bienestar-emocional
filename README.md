# Bimo — Bienestar emocional en el trabajo

## Descripción del proyecto

Bimo es un proyecto académico que consiste en desarrollar una aplicación web para el seguimiento preventivo del bienestar emocional en el contexto laboral. Utiliza una mascota virtual para ofrecer una experiencia amigable, facilitar el registro del bienestar y entregar mensajes de acompañamiento mediante reglas y respuestas predefinidas.

## Objetivo general

Desarrollar una aplicación web que permita registrar el bienestar emocional, consultar la evolución personal y apoyar la identificación temprana de posibles tendencias que requieran atención preventiva, resguardando la privacidad de los usuarios.

## Tecnologías utilizadas

- **Backend:** Python y Flask.
- **Frontend:** HTML, CSS y JavaScript integrado en la aplicación.
- **Base de datos:** SQLite.
- **ORM:** Flask-SQLAlchemy.
- **Entorno de desarrollo:** Visual Studio Code.
- **Control de versiones:** Git y GitHub.
- **Diseño de interfaces:** Figma.

## Funcionalidad implementada actualmente

- Registro de una puntuación de bienestar entre 1 y 5.
- Selección de una emoción asociada.
- Validación de los datos ingresados.
- Almacenamiento de registros en una base de datos SQLite.
- Actualización del registro del día.
- Visualización de los registros recientes.
- Entrega de mensajes y sugerencias predefinidas de acompañamiento.

## Desarrollo futuro del MVP

Se contempla ampliar la aplicación con perfiles diferenciados, seguimiento personal más completo, orientación preventiva basada en reglas e indicadores organizacionales agregados, manteniendo la protección de los registros individuales.

## Ejecución local

El proyecto está preparado para desarrollarse y ejecutarse localmente mediante Python y Flask. Las dependencias deben instalarse en el entorno de Python correspondiente.

## Alcance

Bimo tiene un enfoque preventivo y de autocuidado. No realiza diagnósticos clínicos ni reemplaza la atención de profesionales de salud mental.

## Uso de inteligencia artificial

Se utilizaron herramientas de inteligencia artificial como apoyo al análisis, la planificación y la elaboración de documentación del proyecto. La interacción prevista de la mascota Bimo se basa en reglas y respuestas predefinidas, no en conversaciones abiertas mediante IA generativa.

Bimo — Mascota virtual de bienestar emocional

Descripción del proyecto

Bimo es un proyecto académico que consiste en desarrollar una aplicación web basada en una mascota virtual, orientada a promover el bienestar emocional mediante interacciones y actividades sencillas de autocuidado.

Objetivo general

Desarrollar una aplicación web interactiva que permita a los usuarios identificar y registrar sus emociones, recibir mensajes de acompañamiento y realizar actividades breves de bienestar emocional.

Funcionalidades propuestas

Interacción con una mascota virtual.

Selección y registro de emociones.

Respuestas predefinidas según las opciones seleccionadas por el usuario.

Actividades sencillas de relajación y autocuidado.

Sistema de progreso de la mascota virtual.

Tecnologías previstas

Python

Django

HTML, CSS y JavaScript

SQLite

Git y GitHub

Estado del proyecto

El proyecto se encuentra en su etapa inicial de desarrollo. Las funcionalidades descritas corresponden a los objetivos planificados y se implementarán progresivamente.

Consideraciones

Bimo tiene como propósito promover el autocuidado y el bienestar emocional. No está diseñado para diagnosticar problemas de salud mental ni para sustituir la atención psicológica profesional.
